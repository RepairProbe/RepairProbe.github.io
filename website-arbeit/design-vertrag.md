# Design-Vertrag · 28.10.2026

## Richtung: Reparatur verstehen
Eine ruhige, zugängliche Projektpräsenz. Der Einstieg zeigt den Nutzen und ein ausdrücklich geplantes Radio-Szenario. Fachbegriffe folgen erst nach der verständlichen Erklärung. Keine Produktoberfläche wird vorgetäuscht.

Marke: bestehende Prüfspitze und Cyan #6ac9d7, lokal gehostete IBM Plex Sans und Mono. Papier #f6f7f4, Tinte #173039, Text sekundär #4d6268, Linkfarbe #086575. Dunkle Fläche ausschließlich für das zentrale Prinzip. Die eigenständig mit CSS gezeichnete Radioillustration ist erklärende Dekoration, kein Produktfoto.

Gestaltung: große ruhige Überschriften, asymmetrischer zweispaltiger Einstieg, viel Weißraum, lineare Statuslisten, nummerierter Ablauf mit sechs Schritten. Mobile Reihenfolge folgt der Leserichtung. Keine Verläufe, Animationen, Stockbilder oder gleichförmigen Werbekarten.

Startseite: Nutzen → reales Informationsproblem → geplantes Szenario → Informationsherkunft → Vorhanden/geplant/später → Forschung/Open Source → Person/Kontakt.

Navigation: Start, Prinzip, Projektstand, Technische Basis, Kontakt. Technische Details bleiben auf einer eigenen Seite. Bestehende Seitenadressen bleiben bestehen.

Kontraste mindestens 4,5:1 für Text. Fokus sichtbar, alle Navigationen per Tastatur, Skip-Link, semantische Überschriften, 320 bis 1440 Pixel ohne Überlauf. Illustrationen sind für assistive Technik verborgen. Keine externe Ressource beim Seitenaufruf.

Inhalt: Förderbewerbung in Vorbereitung, nicht eingereicht oder bewilligt; 850 Stunden über sechs Monate; Produktrepository privat; FOSS-Veröffentlichung geplant. Forschung n=1 mit widersprüchlichen Ergebnissen, ohne Wirkungsbehauptung. Alle Radio-Abläufe geplant.
