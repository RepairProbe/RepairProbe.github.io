Independent open-source project

Make repair diagnosis easier to follow.

RepairProbe explores how observations, real measurements, technical sources and AI-assisted interpretation can work together without taking the repair decision away from the person doing the repair.

Important: this is a product and validation question, not a proven claim. AI interpretation is not a measurement.

What is RepairProbe?

A practical evidence layer for repair work.

RepairProbe is software-only and local-first in its core direction. It is intended to connect photos and observations, optional readings from tools already available, technical documentation and a structured repair case.

The project favours simple solutions to real problems, open interfaces and automation where it saves human time.

Who is behind it?

A project initiated by Raik Müller.

Raik's professional background is in the technical/CNC field. Long-standing practical interests include repair, electronics and soldering; additional interests include microcontrollers, self-hosted systems, software and automation.

AI is used as a tool to make technical knowledge and software development more accessible. It does not replace safety rules, deterministic checks, real measurements or human repair decisions.

Evidence model

Keep different kinds of knowledge distinct.

OBSERVED

What a person can directly see or report.

MEASURED

A value actually captured with an available instrument.

RETRIEVED

Information found in a datasheet, schematic or documented case.

INFERRED

A hypothesis derived from the available evidence.

CONFIRMED

A result supported by a counter-check or repair outcome.

Inference is not measurement. A photo must never invent an electrical value.

Current status

A small pre-funding software baseline exists.

The private core repository includes structured measurement events, fail-closed validation, a mock adapter, an append-only evidence store, deterministic fixture replay and a passive-first safety baseline. This proves software integrity only. It does not prove repair success, image understanding or AI quality.
